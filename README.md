# Jarvis

مساعد شخصي تجريبي بواجهة عربية (Next.js) وواجهة API (FastAPI): حسابات، محادثات، مهام وتذكيرات، تحكم صوتي عبر المتصفح، وذاكرة شخصية اختيارية يتحكم بها المستخدم.

## التشغيل

راجع [دليل التشغيل المحلي بالعربية](docs/LOCAL_SETUP_AR.md) لتعليمات Windows وmacOS وLinux. الواجهة على `http://localhost:3000`، وفحص الخادم على `http://localhost:8000/health`، ووثائق API على `http://localhost:8000/docs`.

المتطلبات: Node.js 20+ وPython 3.11+. انسخ `.env.example` إلى `.env` في جذر المشروع. مفتاح `OPENAI_API_KEY` مطلوب للردود الفعلية فقط؛ لا تضع المفتاح في ملفات الواجهة أو Git.

## الاختبارات

```bash
python -m pip install -r backend/requirements-dev.txt
python -m pytest backend/tests -q
npm install --prefix frontend
npm run lint --prefix frontend
npm run build --prefix frontend
```

## الوظائف والحدود

- تسجيل حساب وجلسات محادثة محفوظة في SQLite.
- مهام وتذكيرات مرتبطة بالمحادثات؛ تنبيهات المتصفح تعمل عندما تكون الصفحة مفتوحة.
- ذاكرة شخصية يضيفها المستخدم ويديرها، وتُرسل آخر 20 معلومة كسياق إلى مزود الذكاء الاصطناعي عند طلب رد.
- الإدخال الصوتي وقراءة الرد يعتمدان على دعم المتصفح.

هذه نسخة تطوير وليست مساعدًا قادرًا على تنفيذ أي شيء أو جاهزًا للنشر العام. لا توجد تكاملات بريد أو تقويم أو تنفيذ أوامر على الجهاز. لا تحفظ معلومات حساسة. قبل النشر يلزم مراجعة أمنية وHTTPS وإدارة أسرار ونسخ احتياطي واختبارات تشغيلية. قاعدة SQLite المحلية في `data/` لا ينبغي رفعها إلى Git.
