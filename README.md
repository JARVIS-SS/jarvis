# Jarvis

مساعد شخصي تجريبي بواجهة عربية (Next.js) وواجهة API (FastAPI). يدعم حسابات محلية، جلسات محادثة متعددة، مهامًا، تذكيرات متصفح، وصوتًا وذاكرة شخصية يحررها المستخدم.

## التشغيل

1. انسخ `.env.example` إلى `.env` وأضف مفتاح OpenAI إن أردت ردود النموذج.
2. شغّل الواجهة: `npm install --prefix frontend` ثم `npm run dev --prefix frontend`.
3. في نافذة ثانية: `python -m venv .venv`، فعّل البيئة الافتراضية، ثم `pip install -r backend/requirements.txt` و`uvicorn backend.app.main:app --reload --port 8000`.
4. افتح `http://localhost:3000` وسجّل حسابًا. رابط **ذاكرتي** متاح من شريط التنقل أعلى التطبيق، أو مباشرة عبر `http://localhost:3000/memory`.

## الميزات
- حسابات محلية وسجل محادثات منفصل.
- مهام وتذكيرات وإشعارات متصفح اختيارية أثناء فتح التطبيق.
- إدخال صوتي وقراءة صوتية عبر ميزات المتصفح المدعومة.
- ذاكرة شخصية اختيارية: المستخدم يضيف المعلومات أو يحذفها، ولا يتم حفظها تلقائيًا. تُستخدم آخر 20 معلومة كمعلومات سياقية في ردود النموذج عند تفعيل مفتاح OpenAI.
- APIs للذاكرة تتطلب رمز الدخول وتقيّد البيانات بهوية المستخدم.

## الخصوصية والحدود
لا تحفظ معلومات شديدة الحساسية مثل كلمات المرور. عند استخدام مزود ذكاء اصطناعي، تُرسل الذكريات المضافة صراحةً ضمن سياق طلب المحادثة إليه. حذف الذكريات يزيلها من قاعدة التطبيق، لكنه لا يسحب ما سبق إرساله لمزود الخدمة. هذه النسخة تأسيسية وليست مراجعة أمنية أو جاهزة للنشر العام؛ يلزم HTTPS، تحديد معدل الطلبات، وإدارة أسرار ونسخ احتياطي مناسب.
