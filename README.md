# Jarvis

مساعد شخصي تجريبي بواجهة عربية (Next.js) وواجهة API (FastAPI). يدعم حسابات محلية، جلسات محادثة متعددة، مهامًا، تذكيرات متصفح، وصوتًا وذاكرة شخصية يحررها المستخدم.

## التشغيل

راجع [دليل التشغيل المحلي بالعربية](docs/LOCAL_SETUP_AR.md) لتعليمات Windows وmacOS وLinux. باختصار:

```bash
npm install --prefix frontend
npm run dev --prefix frontend
```

وفي نافذة أخرى:

```bash
python -m venv .venv
# Windows PowerShell: .venv\\Scripts\\Activate.ps1
source .venv/bin/activate
python -m pip install -r backend/requirements.txt
python -m uvicorn backend.app.main:app --reload --port 8000
```

افتح `http://localhost:3000`. فحص الخادم `http://localhost:8000/health`، ووثائق API `http://localhost:8000/docs`. انسخ `.env.example` إلى `.env` وأضف مفتاح OpenAI إن أردت ردود النموذج.

## الميزات
- تسجيل حساب ودخول وخروج، وسجل منفصل لكل مستخدم.
- جلسات محادثة متعددة وسجل محفوظ.
- مهام وتذكيرات مرتبطة بالمحادثات وإشعارات متصفح اختيارية أثناء فتح التطبيق.
- إدخال صوتي وقراءة صوتية عبر ميزات المتصفح المدعومة.
- ذاكرة شخصية اختيارية، يضيفها المستخدم ويحذفها بنفسه، وتُستخدم كسياق لردود النموذج.

## الخصوصية والحدود
لا تحفظ معلومات شديدة الحساسية. عند تفعيل مزود الذكاء الاصطناعي، تُرسل الذكريات التي أضفتها صراحة ضمن سياق طلب المحادثة. حذف الذكريات يزيلها من قاعدة التطبيق لكنه لا يسحب ما سبق إرساله لمزود الخدمة. هذه نسخة تطوير أولية، وليست جاهزة للنشر العام أو مراجعة أمنية. يلزم HTTPS وإدارة أسرار آمنة وتحديد معدلات الطلبات ونسخ احتياطي مناسب قبل النشر.
