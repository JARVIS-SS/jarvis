# Jarvis

مساعد شخصي تجريبي بواجهة عربية (Next.js) وواجهة API (FastAPI). يدعم حسابات محلية، جلسات محادثة متعددة، ومهامًا منفصلة لكل محادثة عبر SQLite.

## التشغيل

1. انسخ `.env.example` إلى `.env` وأضف مفتاح OpenAI إن أردت ردود النموذج.
2. شغّل الواجهة: `npm install --prefix frontend` ثم `npm run dev --prefix frontend`.
3. في نافذة ثانية: `python -m venv .venv`، فعّل البيئة الافتراضية، ثم `pip install -r backend/requirements.txt` و`uvicorn backend.app.main:app --reload --port 8000`.
4. افتح `http://localhost:3000`. ينشئ أول مستخدم حسابه من صفحة الدخول.

## ما يشمله
- تسجيل حساب/دخول/خروج، كلمات المرور مخزنة باستخدام PBKDF2، ورموز جلسة عشوائية مخزنة كـ hash وتنتهي بعد 7 أيام.
- جلسات محادثة متعددة، سجل مستقل لكل جلسة، وإمكانية إنشاء الجلسة وحذفها.
- مهام وتذكيرات مرتبطة بالمستخدم والمحادثة، مع إشعارات متصفح اختيارية أثناء فتح التطبيق.
- يعمل OpenAI فقط عند توفير `OPENAI_API_KEY` من متغيرات البيئة.

## تنبيهات مهمة
هذا إصدار تأسيسي وليس مُدققًا أمنيًا أو جاهزًا للنشر العام. استخدم HTTPS في النشر، أضف تحديد معدل محاولات تسجيل الدخول، نسخًا احتياطيًا لقاعدة البيانات، وإدارة مناسبة للأسرار. توكن تسجيل الدخول محفوظ في localStorage في هذه النسخة. البيانات القديمة ذات الجلسة `default` لا تُنقل تلقائيًا إلى حساب، وقاعدة البيانات تنشأ محليًا داخل `backend/data/jarvis.db`.
